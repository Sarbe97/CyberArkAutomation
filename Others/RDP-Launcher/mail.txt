ubject: PSM Adoption Analysis and New CLI Tool for Your Use

Dear Team,

Over the past several weeks, we have been observing CyberArk usage patterns across the organization. Despite our efforts, we continue to find that:

- Majority of users are retrieving passwords directly from CyberArk instead of using PSM sessions
- PSM session activity remains minimal
- Manual password handling increases security and compliance risks

To improve security and streamline your workflow, we strongly encourage you to start using CyberArk PSM for logging into target machines. As an alternative, we have developed a CyberArk CLI Application to make PSM access more convenient and accessible directly from your command line.

How It Helps

Instead of navigating the CyberArk web portal every time you need secure access, this CLI application lets you:

- Initiate secure PSM sessions directly from your command line with a single command
- Manage your privileged access efficiently from the terminal

All authentication still goes through CyberArk's secure backend, but the CLI provides a faster and more convenient alternative for routine operations.
