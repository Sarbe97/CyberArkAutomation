Subject: Secure Remote Access Made Simple - Now Using Direct RDP via CyberArk

Dear Team,

Over the past several weeks, we have been observing CyberArk usage patterns across the organization. Despite our efforts, we continue to find that:

Majority of users are retrieving passwords directly from CyberArk instead of using PSM sessions

PSM session activity remains minimal

Manual password handling increases security and compliance risks

To improve security and streamline your workflow, we strongly encourage you to use CyberArk PSM for all remote server access. As an alternative to navigating the CyberArk web portal, we are providing pre-configured RDP files that connect to your target servers through CyberArk PSM in the background.

RDP File Configuration
When you receive your RDP file, it will contain the following pre-configured settings:

text
full address:s:[PSM_SERVER]
alternate shell:s:psm /u [TARGET_ACCOUNT] /a [TARGET_SERVER] /c PSM-RDP
username:s:[CYBERARK_USERNAME]
desktopwidth:i:1920
desktopheight:i:1080
session bpp:i:32
Variable Placeholders:

[PSM_SERVER] - Your CyberArk PSM server (e.g., PSM_Server1)

[TARGET_ACCOUNT] - Target account with domain (e.g., user@domain.com)

[TARGET_SERVER] - Target server IP or hostname (e.g., 10.2.5.6)

[CYBERARK_USERNAME] - Your CyberArk login (e.g., u146647)

Example Configuration:

text
full address:s:PSM_Server1
alternate shell:s:psm /u admin@corp.com /a 10.2.5.6 /c PSM-RDP
username:s:u146647
desktopwidth:i:1920
desktopheight:i:1080
session bpp:i:32
Simply double-click the RDP file, and these settings will automatically connect you through CyberArk PSM.
